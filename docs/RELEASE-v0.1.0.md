# FF:O 0.1.0 — Android tester build

- Android Hub with manual tester-password entry.
- Start/Stop local server and health-gated client launch.
- In-Hub game-data download, eight verified parts, streamed extraction.
- Native ARM64 client routing to the phone's localhost server.
- Story and Vortex placeholder coverage from the current restoration build.

Install both APKs; open Hub and use the password supplied separately by Cloud.
Choose Download / repair game data, then Start server and Launch FF:O.
The data parts are fetched by Hub automatically; manual part downloads are
only needed for diagnostics. Allow at least 10 GB of free space for setup.

This is a prerelease. Android startup/playthrough validation is pending;
desktop server transaction checks do not establish native Android playability.
See the README for the placeholder content and remaining restoration gaps.
